# Code of conduct

Short, because it is meant to be read.

## The standard

Be decent to people. Assume the person on the other end is trying to help and
has less context than you do.

Concretely, in issues and pull requests here:

- **A confused question is a good question.** Most people arriving here play the
  game and do not write Python. "It says no marker found and I do not know what
  that means" is a valid report, not a waste of anyone's time.
- **Criticise the code, not the person.** "This misses the case where the route
  changes" is useful. "Did you even test this?" is not, and it is usually wrong
  as well.
- **A report that turns out to be wrong is still worth having.** Several of the
  things fixed in this project were found by somebody saying "that seems off"
  about output that turned out to be correct, which is how the confusing parts
  got found.
- **Nobody is owed your time, including the maintainer.** This is a side project
  for a game. Answers can take a while.

Not welcome: harassment, personal attacks, sexual attention, deliberate misuse
of somebody's name or pronouns, publishing another person's private information,
or following someone here from elsewhere to continue an argument.

## Sharing other people's data

Screenshots from this tool can contain guild chat, whispers, character names and
the marketplace. **Do not post somebody else's chat in an issue**, even if it
arrived in your own screenshot. Crop it or use `.\scrub.cmd`, which never
includes a whole window frame.

This is the one rule specific to this project, and it exists because the tool
takes pictures of a shared multiplayer game.

## If something goes wrong

Report it privately by [emailing the maintainer](mailto:dev.cattarinich@gmail.com),
or through [private vulnerability reporting](https://github.com/delCatta/bdo-autoroute-track/security/advisories/new)
if it is easier. Say what happened and link to it if it is public.

Reports are handled by the maintainer, who will not discuss them publicly.
Depending on what happened, the response is a word in private, an edit, a locked
thread, or a block. Repeated or deliberate harm goes straight to a block.

If the complaint is about the maintainer, say so to the Black Desert Sailing
Discord admins instead.

## Scope

This applies to issues, pull requests, commits and discussions in this
repository. It is not a claim on anything you do elsewhere, with the exception
that harassment following someone from here to another place is still
harassment.
